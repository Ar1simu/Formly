Administrative Security Notice

This release stores records in browser-local storage. Advanced Mode is a user-interface toggle, not authentication.

Because this app is hosted as a static website, visitors may inspect client-side JavaScript and locally stored data. Do not enter sensitive information into this workspace.

A future authenticated backend is required for genuinely administrator-only access to prediction data.
